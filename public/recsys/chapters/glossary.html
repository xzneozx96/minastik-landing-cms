Glossary

A single alphabetical list of every term defined across the book. Each term is defined in full in its home chapter; this page gathers them for quick reference and search.

A

Term Meaning
A/B test (online eval) Serve two models to live user halves and compare a business metric — the real verdict.
Ablation A test that removes one part of a method to see what the part was worth (§4).
Ablation study An experiment that removes one component of a model at a time to see what each contributes (§8.6, Step 0).
Activation function The fixed, simple nonlinear bend a layer applies to its weighted sums, e.g. the sigmoid or ReLU (§3).
Activation function \(\phi\) Nonlinear function applied to \(z\) (sigmoid, tanh, ReLU); its output \(a\) is the neuron’s activation.
Activations The numbers a layer outputs; each unit’s is computed from the previous layer’s (§5.2).
Adam An optimizer that divides each parameter’s step by the recent size of its own gradient (§5; Kingma and Ba, 2015).
Adaptor A small trained network that maps the LLM’s vector into the recommender’s space and shrinks it, as in KAR (§4).
Adjacency matrix \(A\) The whole graph’s connections as a square grid of 0/1.
Advantage How much better an output scored than the group’s mean reward, divided by the group’s standard deviation in GRPO (§4).
Agentic recommender An LLM that plans, remembers, and calls tools over multi-turn conversation (§2.4).
Alignment A positive pair is pulled together: two views of one node, or in DirectAU an interacting user and item (§3.3).
Alignment & uniformity Pull positives together / spread embeddings on the sphere (DirectAU); its popularity-weighted uniformity is said to help reduce exposure bias (items the system showed more got more clicks; a claim of the DirectAU paper, not tested here).
Alignment loss (RLMRec) Ties the vectors of LLM-written user/item profiles to the collaborative (CF) embeddings — contrastively (RLMRec-Con) or by rebuilding masked profiles (RLMRec-Gen).
ALS / iALS Alternating least squares: fix \(Q\) and solve for \(P\) in closed form, then swap. iALS is the implicit-feedback version, weighting each cell by a confidence (§5).
Anchor The node \(i\) whose first view a contrastive loss compares with all second views (§3.2).
Angle (of an arrow) Its direction, measured from the romance axis and positive toward action (§8).
ANN Approximate nearest-neighbor search — fast, slightly-inexact vector retrieval; the candidate-generation engine.
ANN (approximate nearest neighbor) Fast similarity search that makes dot-product retrieval scale to millions of items.
ANN (approximate nearest-neighbor) Fast vector search that returns almost the closest vectors to a query, trading a little accuracy for large speed-ups; how embedding retrieval is served (Training and Serving a Recommender §7).
ANN (Approximate Nearest-Neighbor) search Search that finds almost-the-best items by consulting a precomputed index instead of scoring every item, trading exactness for a large speed-up.
AP / MAP Average Precision (Precision@\(k\) summed over hit positions, divided by $
API (application programming interface) model One you cannot download: your program sends each request to the maker’s servers over the internet and pays per use.
Approximate nearest neighbor (ANN) Finding items whose vectors are close to a query vector by skipping most of the catalogue, at the price of sometimes missing the very best one (§15).
Arm One choosable option (an item); “pulling” it = showing it. From the slot-machine metaphor.
Arm (tower, stream) One of the two parallel sub-networks whose outputs meet in one logistic head; the papers also say tower or stream. Not the retrieval chapters’ tower, an encoder of only the user or only the item.
Attention \(\mathrm{softmax}(QK^\top/\sqrt{d_k})V\): each position takes a blend of the value vectors of the positions it may see, weighted by how well its query matches their keys (§4.1).
Attention mask Which tokens each token may look at: all of them (bidirectional — BERT, BERT4Rec) or only itself and earlier ones (causal — GPT, SASRec; §5.1).
Attention weight The softmax of the scaled query-key scores: how much one position attends to another; positive, summing to \(1\).
Attributed / featureless Whether nodes carry input feature vectors; recsys nodes are featureless (IDs only).
AUC Area under the ROC curve: the fraction of (positive, negative) pairs ordered correctly; BPR is its smooth stand-in (§9).
AUC / ROC Area Under the Receiver Operating Characteristic (ROC) Curve = P(score of a random relevant > random irrelevant) = the fraction of correctly ordered (relevant, irrelevant) pairs.
Augmentation A small change to the input that should not change what it is (a flipped photo is the same cat); the recipe comes from image learning (SimCLR) and gives GCL its views (§3.1).
Autoencoder A network trained to reproduce its own input through a narrow middle layer (§6.2).
Autoregressive decoding Generate one token, append it, run the model again, repeat — the GPT generation loop (SASRec’s next-item prediction is one step of it; §5.4).
Autoregressive generation Writing an output one token at a time, each token chosen given the ones before it (§2.2).
Auxiliary task The extra, label-free objective added alongside the main (BPR) loss.

B

Term Meaning
Back-propagation Computing all weight-gradients by the chain rule, backward through the net.
Back-propagation (backprop) The chain rule run backward from the loss, to find how the loss changes with every weight (§3).
Backbone The base model an extra loss is added to; here LightGCN (§1, §7).
Backbone, lift The base model a method is added to, and the gain over it (§4, RLMRec).
Bag-of-words vector A paper described by which vocabulary words occur in it: one entry per word; in the standard Cora files (\(1{,}433\) words) each entry is \(1\) if present and \(0\) if absent; counts in our toy (§6).
Bandit An MDP in which actions never change the next state (one state, or a fresh context each round); such actions are called one-shot.
Bandit feedback You observe the reward only for the action you took, never the alternatives.
Base-rate effect A rare condition (low prior) makes even an accurate test’s positives mostly false.
Baseline A simple model to compare others with, such as plain matrix factorization with BPR (§15).
Basis A set of vectors from which every vector can be built in exactly one way as a weighted sum.
Batch / Layer Norm Re-center/re-scale activations for training stability (LayerNorm is the normalization the Transformer uses, §7).
Batch normalization / layer normalization Re-center and re-scale activations across a batch / within one example: \([2,4,6]\to[-1.22,0,1.22]\) (§5.2).
Bayes’ rule posterior \(\propto\) likelihood \(\times\) prior.
Bayesian Personalized Ranking (BPR) A ranking loss for implicit data: train so that an item the user interacted with scores above a randomly sampled unobserved one (§1; Loss Functions & Regularizers §9).
Beam search A search that keeps only the best few partial lists at each step (§4).
Beam search (decoding) Keep the \(W\) best partial ID prefixes per step; the completed tuples, ranked, are the top-\(K\) recommendations (§2.2).
Beam width \(W\) How many partial candidates beam search carries forward at each step; the surviving completed tuples, ranked by probability, are the top-\(K\) (§2.2).
Benchmark framework RecBole / Cornac / Elliot / Microsoft Recommenders / LensKit — unified datasets + models + protocol.
Benchmaxxing Training on (or near) benchmark data so a high score can reflect memorization, not ability — why one leaderboard number is untrustworthy.
Bernoulli One yes/no with parameter \(p\); \(-\log\) → BCE.
Bernoulli trial One try with two outcomes, such as click / no click, with unknown chance \(\mu\).
BERT Bidirectional Encoder Representations from Transformers: trained by masked language modeling (pick about 15% of the tokens, mostly replaced by [MASK], and predict them), originally with a next-sentence objective that was later often dropped; an encoder for understanding text → embeddings (Devlin 2019; §5.1).
BERT4Rec A bidirectional Transformer trained with the cloze (masked-item) objective.
Beta Distribution over a probability; conjugate prior for Bernoulli.
Beta posterior \(\text{Beta}(1+s,1+f)\) for \(s\) clicks, \(f\) non-clicks; conjugate to the Bernoulli click.
Bias–variance trade-off Error splits into systematic mis-fit (bias) and sensitivity to the sample (variance); model complexity trades one against the other (§4).
Biases \(\mu\), \(b_u\), \(b_i\) The global mean rating, a user’s generosity or harshness, and an item’s broad appeal; added before the dot product in biased MF (§5).
BIGRec Bi-step grounding: an instruction-tuned LLM writes the next item by name, and the written text is matched to the nearest catalog item by embedding (§5).
Binary entropy The entropy of a two-outcome variable with probabilities \(\theta\) and \(1-\theta\): \(-\theta\log_2\theta-(1-\theta)\log_2(1-\theta)\), which peaks at \(1\) bit for \(\theta=\tfrac12\) (§7).
Bipartite graph Nodes in two groups; edges only cross between groups (users ↔︎ films).
Bit The information in one fair coin flip; an event of probability \(\tfrac12\) carries \(1\) bit, and \(-\log_2 p\) bits in general.
Bits / nats Units of entropy: \(\log_2\) gives bits, \(\ln\) gives nats; \(1\) bit \(=\ln 2\approx0.693\) nats (§7).
Blockbuster A film that very many people watch: a node of huge degree (§13).
BM25 / hybrid retrieval “Best Matching 25”, the standard keyword-scoring refinement of TF-IDF / blending its (sparse) scores with embedding (dense) scores in one query.
BM3 A multimodal recommender that trains without negative samples by comparing an embedding with a dropout copy of itself (§5).
Bonferroni / Holm Multiple-comparison fixes for \(m\) tests: Bonferroni compares each \(p\) to \(\alpha/m\); Holm is a stepwise version that is never more conservative: it keeps every result Bonferroni keeps, and sometimes more (for \(p=0.012,\,0.020,\,0.024\) Bonferroni keeps one, Holm all three; §8.6 Step 3).
Bootstrap Estimating how much a score wobbles by re-drawing the test cases at random with replacement (a case may be drawn more than once) many times and recomputing the score each time; it needs no bell-shape assumption (Evaluation Metrics §11d; named in §8.7).
BPR Bayesian Personalized Ranking: a loss that teaches a recommender to rank an item a user chose above one they did not; it applies a sigmoid to the score gap (§3).
BPR loss Pairwise ranking loss: push observed pairs above sampled negatives; Ann’s triple (Titanic over Matrix) costs \(0.027\) (§15).

C

Term Meaning
Calibration A model is calibrated when the numbers mean what they say: of impressions scored \(0.3\), about \(30\%\) are clicked (Evaluation Metrics §11).
Calibration / ECE A model is calibrated if items it scores \(0.8\) are clicked about \(80\%\) of the time; the Expected Calibration Error averages the per-bin absolute gap between predicted and observed rates, weighting each bin by its share of predictions.
Capacity The range of functions a model can express; a weight matrix on already-trained vectors adds none (§14).
Categorical One of \(K\) classes; \(-\log\) → cross-entropy; paired with softmax.
Causal mask Lower-triangular mask: position \(t\) may attend only to positions \(\le t\) (no peeking at the future).
CDF \(F(x)\) Cumulative distribution function \(F(x)=\Pr(X\le x)\) — the running total of probability; a different function describing the same distribution.
Cell state The LSTM’s protected memory line, edited only by a forget multiply and a write add (§3.3).
Censored reward A reward not yet known: no click so far, but one may still come (§7).
Central Limit Theorem The average of many independent noisy pieces is approximately bell-shaped around the truth; with enough pairs it keeps the \(t\)-test a fair approximation when the differences are not exactly normal, but not with a handful (§8.3, Fact 2).
Chain rule Derivative of \(f(g(x))\) = \(f'(g)\cdot g'\); the basis of back-propagation.
Characteristic equation / polynomial \(\det(A-\lambda I)=0\); its left side is the characteristic polynomial, and its roots are the eigenvalues.
Chebyshev polynomials The family \(T_0=1\), \(T_1=\lambda\), \(T_{j+1}=2\lambda T_j-T_{j-1}\): the same filters a plain polynomial can express, the basis ChebyCF interpolates in; interpolating at Chebyshev points spreads the error nearly evenly over \([-1,1]\).
CIN (compressed interaction network) xDeepFM’s explicit-interaction arm: crosses between whole field vectors, mixed into a few new vectors by learned weights.
Citation network A graph whose nodes are papers and whose edges are citations; the GCN paper treats them as undirected (§6).
Client / server Devices holding private data / the coordinator that aggregates their updates.
Closed-form / training-free CF Recommenders that apply a fixed filter with no gradient training (GF-CF, PSGE, by their authors’ account).
Cloze objective Hide some of a user’s items and predict them from the rest (BERT4Rec; §10).
Codebook / codeword A small fixed menu of prototype vectors (the codebook); each entry is a codeword. Quantizing a vector means replacing it by its nearest codeword’s symbol (§2.2).
Cold item A film with almost no clicks yet (§4 box).
Cold start No history yet for a new user/item; CF cannot act.
Cold start (serving) Having no learned vector for a brand-new item to put in the index, or for a brand-new user to query it with (§8).
Cold-start A new user or item with no history, so no learned row to look up (§3).
Collaborative filtering (CF) Recommend using interaction patterns across users (no content).
Collaborative signal What can be learned from who interacted with what (From Graphs to LightGCN, Self-Supervised & Contrastive Learning, The Spectral / Graph-Filter View), independent of item content.
Column space / image Every output a matrix can produce — all weighted sums of its columns.
Complement \(\neg B\) “Not \(B\)”; \(\Pr(\neg B)=1-\Pr(B)\) (§1).
Component / entry One number inside a vector.
Computational graph One node per quantity, one arrow per “is computed from” — the picture back-propagation walks backward (§5).
Concat (early fusion) Append the LLM feature vector to the ID embedding — the quick first try, at the cost of a fatter serving vector. A frozen vector adds a fixed content score; only an adaptor or an FM or MLP scorer lets the model re-weigh it (§4).
Concatenation Gluing vectors side by side: three layers of \(2\) numbers give \(6\) numbers per node (§14).
Condition number The largest singular value divided by the smallest, \(\sigma_1/\sigma_{\min}\) (§6); a huge value means a solve or inverse with that matrix is numerically unreliable.
Conditional probability \(\Pr(A\mid B)\) Probability of \(A\) given \(B\) occurred \(=\Pr(A\cap B)/\Pr(B)\).
Confidence \(c_{ui}\) How much to trust an implicit signal: \(c_{ui}=1+\alpha\,n_{ui}\), growing with the play count \(n_{ui}\) (§5).
Confidence interval (CI) \(\bar d \pm t^{*}s_d/\sqrt n\); the effect size with its uncertainty. A \(95\%\) CI excludes \(0\) exactly when the two-sided test at \(\alpha=0.05\) is significant (a \(99\%\) CI goes with \(\alpha=0.01\); §8.5, §8.6 Step 4).
Conjugate prior A prior whose posterior is the same family (Beta↔︎Bernoulli).
Consistent policy One whose regret grows more slowly than any power \(T^{c}\) on every bandit of the class; none can beat \(\ln T\) growth (Lai and Robbins, §2).
Constrained decoding Restricting what the model may generate to a valid vocabulary (here, real item identifiers), so an invalid answer cannot be produced at all (§2.2).
Content-based filtering Recommend items similar (in features) to what the user liked.
Context (context window) The longest input a model reads at once, in tokens: “8K context” \(\approx\) 8,000 tokens (word pieces). Longer text is cut off.
Context vector The weighted average of the values under the attention weights; the summary that scores the next item (§4).
Contextual bandit The reward depends on a context (user/item features); LinUCB models it linearly.
Contour (level set) A curve along which \(f\) keeps one constant value, like a height line on a map; the gradient is perpendicular to it (§4).
Contrastive (InfoNCE) term Added to the recommender’s loss: it pulls a node’s collaborative and projected semantic vectors together (the numerator) and pushes its collaborative vector away from other nodes’ semantic vectors (the denominator).
Contrastive learning SSL pretext: pull a node’s two views together, push other nodes apart; needs negatives (DirectAU: no, §3.3); discriminative mechanism (this chapter’s own reading, not a standard label; §6.3).
Contrastive learning / views Learning embeddings by comparison: two views of the same thing are pulled together, other things pushed apart (§2.4).
Convex Curves up everywhere: for a function with second derivatives, one variable \(f''\ge0\), many variables a Hessian that is PSD at every point. A bowl, a trough, or a slope with no bottom (like \(e^x\)) — no bad local minima; any minimum is global.
Cosine similarity \(\dfrac{\mathbf{u}\cdot\mathbf{v}}{\lVert\mathbf{u}\rVert\lVert\mathbf{v}\rVert}\in[-1,1]\) for nonzero vectors; direction agreement, ignoring length.
Cost / objective / criterion Near-synonyms for loss (cost = total; objective = neutral; criterion = the code object).
Coverage The fraction of the catalog that ever appears in anyone’s top-\(K\) list (§6).
CPU / GPU / RAM / VRAM The general-purpose processor / the chip that does thousands of multiplications at once / the computer’s fast working memory / the GPU’s own memory, which must hold the whole model.
Credit assignment Deciding which earlier action deserves credit for a reward that arrives later.
Critical / stationary point Where \(f'(x)=0\) (many variables: \(\nabla f=\mathbf 0\)): peak, valley, plateau or saddle.
Critical value The cutoff that pure luck exceeds only \(\alpha\) of the time (\(2.776\) for df \(=4\), \(\alpha=0.05\), two-sided) (§8.3).
Croissant MLCommons machine-readable dataset-metadata standard (2024); NeurIPS encouraged a record in 2024, worded it “should use” in 2025 and “must use” in 2026, with the Responsible Artificial Intelligence (RAI) fields only requested in the 2026 call (the organizers’ post of 4 May 2026 requires them, §6).
Cross network Stacked layers that raise interaction degree by one each, explicitly and at linear cost (\(2d\) parameters per layer). DCN = a cross network beside a deep MLP.
Cross-encoder A model that reads a (user, item) pair together in one forward pass, so its score cannot be precomputed. A specialist reranker is usually one, and it is not an LLM (§2.1).
Cross-entropy / BCE / log loss Classification loss; average code length (nats with \(\ln\), bits with \(\log_2\)) to encode the truth \(p\) with a code built for the prediction \(q\); BCE = −log-likelihood of a Bernoulli (categorical cross-entropy: of a categorical).
Cross-entropy \(H(p,q)\) \(-\sum p\log q\); surprise of \(p\)’s outcomes scored by model \(q\) — the standard classification loss.
Cross-view alignment Pulling a node’s two embeddings (collaborative \(\mathbf{e}_i\) and semantic \(\mathbf{s}_i\)) together with InfoNCE (§3).
CTR (click-through rate) \(P(\text{click}\mid \text{user, item, context})\); the score the ranking stage predicts.
CTR / impression Click-through rate \(=\) clicks \(/\) impressions, where an impression is one showing of an item to a user.
Curvature How a curve bends: \(f''\) in one variable; in many, the second derivative along a chosen direction (§6).
Cutoff \(K\) The list length in Recall@\(K\) (not the layer count \(K\) of §3.4): only a user’s top \(K\) films count (§7).

D

Term Meaning
\(D^{-1/2}\) The degree matrix with each diagonal degree replaced by \(1/\sqrt{\deg}\) — an entry-by-entry shortcut that works only because \(D\) is diagonal (§7).
Data augmentation Train on randomly perturbed copies of inputs; one history \([A,B,C,D]\) gives four views (§5.2).
Data leakage Test-period information seeping into training; silently inflates every metric.
DCG / IDCG / NDCG Discounted Cumulative Gain (gains \(2^{\text{rel}}-1\), each divided by \(\log_2(i+1)\) at rank \(i\)) / its ideal / the normalized ratio in \([0,1]\).
DCNv2 The cross network with a full weight matrix per layer instead of a vector; its authors report it better than DCN, a report §9 says to test (low-rank form and a mixture of experts keep it affordable).
Debiasing Methods that correct for users rating mostly what they chose to see (§7).
Decision tree / information gain A flowchart of yes/no questions that sorts examples into groups / how much a question reduces the entropy of the labels; the tree asks the question with the largest gain first (§7).
Decoder A network that turns an embedding back into the input it came from; the generative end of a network (§6.3).
Decoy items, hybrid filling Randomly sampled unrated items whose gradients are uploaded with virtual ratings filled in (the user’s average rating or a predicted one), so the real ones do not stand out; \(\rho\) decoys per rated item (§3).
DeepFM Wide & Deep with the wide arm replaced by an FM, sharing one embedding layer; no hand-crossing.
Degree How many neighbors a node has.
Degree matrix \(D\) Diagonal matrix of degrees; used for normalization.
Degrees of freedom The number of values still free to vary once their mean is fixed: \(n-1\) for \(n\) runs (\(4\) for \(5\) seeds).
Degrees of freedom (df) \(n-1\) for the paired test; sets which Student-\(t\) curve gives the \(p\)-value.
Demographic parity Equal selection / exposure rate across groups.
Density Interactions \(\div\) (users \(\times\) items) — the share of the user–item grid that is filled. The graph-CF trio sits near \(0.1\%\) (§2), but MovieLens-1M is about \(4.5\%\) (\(1{,}000{,}209/(6{,}040\times3{,}706)\)) and Netflix about \(1.2\%\) (\(100{,}480{,}507/(480{,}189\times17{,}770)\)), so check.
Derivative \(f'(x)\) Instantaneous rate of change = slope of the curve at a point.
Determinant \(\det A\) Area/volume-scaling factor (\(ad-bc\) for \(2\times2\)); equals the product of the eigenvalues (shown here for \(2\times2\)); \(\det=0\) ⇒ collapses a dimension / non-invertible.
Diagonal matrix A matrix whose only possibly-nonzero entries lie on its diagonal; it just scales each axis (its singular values are the absolute values of its diagonal entries, put in order of size).
Difference quotient \(\frac{f(x+h)-f(x)}{h}\) — rise over run before taking \(h\to0\).
Differential privacy Add calibrated noise to updates so that how much any single user’s data can be inferred is bounded — by a privacy budget \(\varepsilon\) (smaller means more noise and more privacy; not the exploration rate \(\varepsilon\) of the Bandits chapter), not reduced to zero; §3’s numbers are not calibrated to any \(\varepsilon\) (Dwork et al., 2006; Abadi et al., 2016).
Differentiate Compute a derivative (limit of differences).
Dimension How many components a vector has (\(\mathbb{R}^d\) = all \(d\)-vectors).
Direct preference optimization (DPO) / S-DPO A loss that learns from pairs of a preferred and a rejected output with no separate reward model; Softmax-DPO (S-DPO) widens the pair to one preferred item against several negatives (§4).
DirectAU A negative-free loss (Wang et al., KDD 2022) that optimizes alignment and uniformity directly, instead of via a softmax; its positive pair is a user and an item she interacted with, not two views (§3.3).
Directed / undirected Whether an edge has a direction (A→B \(\ne\) B→A) or not.
Directional derivative Rate of change of \(f\) along a unit direction \(\hat{\mathbf d}\): \(\nabla f\cdot\hat{\mathbf d}\).
Discount \(\gamma\) How much a later reward is worth vs. now; \(\gamma\to0\) is myopic (cares only about the immediate reward, like a bandit’s objective), \(\gamma\to1\) far-sighted.
Discriminative vs. generative Axis 1 — whether a model learns \(p(y\mid x)\) (a boundary; can’t generate) or \(p(x)\)/\(p(x,y)\) (the data; can sample). BPR/LightGCN is discriminative; VAEs/LLMs are generative.
Distributional hypothesis “You shall know a word by the company it keeps” (Firth 1957; Harris 1954) — words in similar contexts have similar meanings; word2vec turns this into similar vectors (§2.1).
Diversity Average dissimilarity within a recommended list.
DNN (deep neural network) DeepFM’s name for the MLP arm — the same object as Wide & Deep’s deep arm.
Dot / inner / scalar product \(\mathbf{u}\cdot\mathbf{v}\) \(\sum_i u_iv_i\); one number measuring agreement.
Dot product Multiply-and-sum two embeddings → a similarity / ranking score.
DPO (direct preference optimization) Fine-tuning a model on pairs of preferred and rejected outputs so it favors the preferred kind; the “alignment” of OneRec’s training, not the embedding alignment of §3 (§2.2).
Dropout Randomly zero units during training; an ensemble-like regularizer; “edge dropout” on graphs.
Dynamic negative sampling Keeping hard negatives hard: draw a few un-clicked candidates and keep the one the current model scores highest (§3).

E

Term Meaning
Early stopping Stop when validation stops improving; implicit regularizer.
EasyRec A language model tuned with contrastive learning so that vectors from text line up with collaborative behavior: the feature-encoding cell of the enhancer (§2.3).
Edge A connection (user liked film, rated \(4\) or \(5\)).
Effect size The magnitude of the difference (\(\bar d\)); report it alongside \(p\) (significance \(\ne\) size).
Eigenbasis A basis made of eigenvectors; a real symmetric matrix always has one of mutually perpendicular unit eigenvectors (the spectral theorem, §5, stated without proof).
Eigenvalue One of the two extreme curvatures of a symmetric \(2\times2\) Hessian; their product is \(D\) (§6 optional box; Linear-Algebra primer §5).
Eigenvalue \(\lambda\) The stretch factor of an eigenvector.
Eigenvector A direction a matrix only stretches, not rotates: \(A\mathbf{v}=\lambda\mathbf{v}\).
Eigenvector \(\mathbf{v}\) A special direction a matrix only stretches (not rotates): \(\tilde{A}\mathbf{v}=\lambda \mathbf{v}\). The graph’s eigenvectors are its “frequency patterns.”
Elastic net L1 + L2 combined; “stretchable net” keeping correlated features.
ELBO Evidence lower bound: a computable lower bound on the data’s log-likelihood that a VAE (variational autoencoder) maximizes; Mult-VAE minimizes reconstruction loss + β·KL, which is exactly −ELBO when β = 1 (§11).
Element-wise product \(\odot\) Multiply two vectors number by number: \([2,-2]\odot[2,0]=[4,0]\); the dot product is the sum of the result (§14).
Elo The chess rating system, reused for chatbot arenas: beating a strong opponent raises your rating more than beating a weak one.
Embedding A learned vector representing a user/item as a point in space.
Embedding (layer) The table that replaces each field’s active category by its learned dense vector \(\mathbf e_f\); one copy, read by every arm that needs it.
Embedding layer A learnable lookup table; id → its row (= one-hot × matrix); the input side for discrete data.
Embedding matrix \(E\) All embeddings stacked, one row per node: \(N\times d\); reading row \(k\) is the lookup of Neural Networks & Back-propagation §3 (§4).
Empirical mean An arm’s clicks divided by its pulls so far, written \(\hat\mu_i\); \(2\) clicks in \(3\) pulls give \(0.667\) (§3).
Encoder Whatever turns raw inputs into embeddings; here, LightGCN’s propagation over the ID table (§3.1).
Encoder / decoder An encoder reads a sequence into context-aware vectors, every token seeing every other (BERT); a decoder writes text one token at a time, each token seeing only itself and earlier ones (GPT; §5.1).
Enhancer / reranker (LLM role) Recsys LLM roles: generate item/user text features / re-order a candidate list — not chat.
Enhancer pipeline Using an LLM offline to manufacture features for a fast collaborative backbone that serves.
Enhancer-style An LLM enriches the inputs of an existing recommender instead of replacing it (§17).

MAP Maximum A Posteriori; the \(\theta\) at the peak of the posterior — it maximizes likelihood \(\times\) prior, i.e. minimizes loss \(+\) regularizer.

Markov chain (first-order) Next item depends only on the last one; transitions estimated by counting.

Matrix A rectangular grid of numbers; also a linear transformation of vectors.

Maximum-entropy model Among all distributions that match what you know, the most uncertain one: knowing nothing about a die, \(\tfrac16\) for each face (§7).

Mean pooling / [CLS] Two ways to get one vector per text: average the token vectors, or read BERT’s summary token (§5.2).
Median The middle value once the data are sorted; the single value that minimizes the total absolute error (§2).
Memory-based CF Predict from similar rows/columns of \(R\) at query time (\(k\)-NN).
Message passing Another name for one graph-convolution step (also called propagation): every node sends its vector along its edges, and replaces its own with the weighted sum it receives.
Mini-batch A small group of training triples used for one update (§15; Neural Networks & Back-propagation §6).
Minibatch A handful of training examples drawn at random; SGD estimates the gradient on it (§5).
MIPS (Maximum Inner-Product Search) Finding the item vectors with the largest dot product against a query: what top-\(K\) scoring is. It coincides with nearest-neighbor search for every query when all the item vectors have the same length.
Mixture of experts Several small sub-models whose outputs a learned gate weights input by input.
ML-20M MovieLens 20M, a standard film-rating data set: 138,493 users, 27,278 films, 20,000,263 ratings, 0.53% of the cells filled (§1).
MLE Maximum Likelihood Estimate; \(\theta\) that best explains the data.
MLP Multi-layer perceptron — a feedforward stack of fully-connected layers.
MNAR data Missing-Not-At-Random: whether an interaction is observed depends on what the system chose to show — recommender logs are the textbook case (the opposite, missing completely at random, is pure coin-flip missingness).
Mode The most plausible value — where a distribution peaks (for a continuous variable the height of the curve at the mode is a density, not a probability: §1); for Beta\((\alpha,\beta)\) with \(\alpha,\beta>1\) it is \((\alpha-1)/(\alpha+\beta-2)\) (§2, §6).
Model card The documentation page a publisher posts beside a released model: size, license, training data, scores. The primary source for every license claim in this appendix.
Model-agnostic Added on top of an existing recommender, whichever one it is; RLMRec is described so by its authors (§17).
Model-based CF Learn a compact model first (e.g. matrix factorization).
MoE (mixture of experts) Several specialist sub-networks plus a trained gate that weights them and sums their outputs; KAR’s adapter for turning LLM knowledge into features (§2.3).
MoE (mixture-of-experts) A model that holds many parameters but activates only a few per token — compute per token is below what the total size suggests, but every expert must still sit in memory.
Momentum Gradient descent that steps on a running total of recent gradients, \(v\leftarrow0.9\,v+g\) (§5).
Momentum / Adam SGD upgrades: a velocity term / a per-parameter adaptive step (§6).
Monotonic Here, increasing (a bigger input always gives a bigger output), like \(\log\) and \(e^{x}\), so it keeps the ranking of any list (§3).
MRR Mean Reciprocal Rank — each user’s reciprocal rank (RR), \(1/\)rank of the first relevant item (\(0\) if none in the top-\(K\)), averaged over users.
MSE / squared loss Mean of squared errors; from Gaussian noise of the same spread for every point; outlier-sensitive.
MTEB / ann-benchmarks / LMArena / CoNLL The standard benchmarks and leaderboards for embeddings / vector indexes / chat-LLMs / NER. Priors, not verdicts.
Mult-VAE A variational autoencoder for recommendation with a multinomial likelihood; loss = reconstruction + \(\beta\cdot\)KL (§11).
Multi-head Several attentions (“heads”) in parallel with different learned projections; their outputs are concatenated and mixed back to length \(d\) by \(W_O\) (§4.3).
Multi-head self-attention Each field’s new vector is a weighted mix of all the fields’ vectors, the weights computed from dot-product scores and a softmax; several heads do it independently (AutoInt, §8; built in Representation Learning & the Transformer).
Multi-label Several independent yes/no labels at once, such as a film that is both a comedy and a drama; each gets a sigmoid (§3).
Multiple comparisons Running several tests at once: each carries its own \(\alpha\) chance of a false positive, so the chance that at least one fires by luck grows (\(1-0.95^{3}\approx0.14\) for three tests; §8.5, §8.6 Step 3).
Mutual information How much knowing one variable tells you about another: the KL divergence between their joint distribution and the product of their separate ones; zero exactly when they are independent (§7).
Mutual information (MI) How much knowing one of two quantities tells you about the other. For a batch of \(N\) nodes, \(\log N-\mathcal L_{\text{cl}}\), with the loss averaged over the batch, is a lower bound on the MI between the two views (§7; Probability & Statistics for Machine Learning §7). RLMRec frames its alignment as maximizing it.

Orthogonal Perpendicular; dot product \(0\).

Policy \(\pi(a\mid s)\) The learned rule mapping a state to an action (\(\pi\) names the policy, not \(3.14159\)); what RL optimizes. Polynomial filter A filter that is a polynomial in \(\tilde{A}\) (what LightGCN layers compute).
Popularity baseline A simple recommender that shows everyone the same most-popular items.

Popularity bias (in eval) Popular items dominate the test set, so pushing them inflates accuracy metrics.
Popularity bias / long tail A recommender over-suggesting already-popular items at the expense of the long tail of rarely seen ones (§2.4).
Position bias Higher-ranked slots draw more clicks regardless of true relevance.

Pre-activation \(z\) (logit, for a classifier’s last layer) The raw score \(\mathbf{w}\cdot\mathbf{x}+b\) before the activation; for layer \(\ell\), the vector \(\mathbf z^{(\ell)}=W^{(\ell)}\mathbf h^{(\ell-1)}+\mathbf b^{(\ell)}\), starting from \(\mathbf h^{(0)}=\mathbf x\).

Precision@K Of the \(K\) shown, the fraction relevant.
Predicted score \(\hat y\) The dot product of a user’s and an item’s embeddings (§4).
Predictive learning SSL pretext: predict a property derived from the data (e.g. a masked item/attribute); one correct answer, no negatives; discriminative mechanism (this chapter’s own reading, not a standard label; §6.3).
Prefix The beginning of a list, \((i_1,\dots,i_{t-1})\): the items seen so far, in order.
Pretext task The self-supervised literature’s name for the auxiliary task; the two words mean the same thing (§6.2).
Pretraining Train a big Transformer on a huge corpus with a self-supervised objective, then reuse it (§5).
Prior and posterior Belief about a click chance before data (prior) and after data (posterior).
Prior \(p(\theta)\) Belief about \(\theta\) before data.
Product rule \((fg)' = f'g + fg'\) — the derivative of a product is not the product of the derivatives (§2).
Production The live system that answers real users’ requests, as opposed to an experiment on saved data.
Profile A short LLM-written description of a user’s taste or an item’s character, used as input to an embedder.
Projection \(\mathrm{proj}_{\mathbf{v}}\mathbf{u}\) The shadow of \(\mathbf{u}\) on \(\mathbf{v}\)’s line, \(\frac{\mathbf{u}\cdot\mathbf{v}}{\lVert\mathbf{v}\rVert^{2}}\mathbf{v}\); in an orthonormal basis a coordinate is just a dot product.

Prompt The text handed to an LLM: the question plus whatever it should know (§2).
Propensity The probability \(p\) that the logging policy took the action it did; a film shown with \(p=0.1\) counts \(10\) times per click (§7).

SASRec / BERT4Rec Sequential recommenders: a causal (left-to-right) / bidirectional (masked) Transformer over the item history (§4.4).
Scalar A single number (as opposed to a vector); multiplying by one scales a vector.
Scaled cosine error GraphMAE’s loss: the mean over hidden nodes of \((1-\cos(\mathbf x,\mathbf z))^{\gamma}\) with \(\gamma\ge1\); at \(\gamma=1\) it is \(1-\cos\) (§6.2, §6.4).
Second derivative \(f''\) Rate of change of the slope = curvature.
Second-derivative test At a critical point of \(f(x,y)\), \(D=f_{xx}f_{yy}-f_{xy}^2\): \(D>0,\ f_{xx}>0\) bowl (min); \(D>0,\ f_{xx}<0\) cap (max); \(D<0\) saddle; \(D=0\) silent (§6).
Secure aggregation The server sees only the sum of client updates, never any individual one (Bonawitz et al., 2017).
Selection / exposure bias Only items the system showed can get feedback; un-shown items look “disliked” by silence.
Self-attention Attention of a sequence to itself (Q, K, V all from the same tokens; §4.1).
Self-loop An artificial edge from a node to itself, so that a node counts itself among its neighbors; present in GCN and NGCF, absent in LightGCN (§6, §14).
Semantic embedding A fixed-length vector encoding the meaning of the profile text (from a frozen sentence encoder), distinct from the CF latent space.
Semantic ID A short sequence of content-derived codewords identifying an item (a quantized text embedding) (§2.2).
Semi-supervised node classification Predicting the label of unlabeled nodes when a few nodes are labeled; the task the GCN paper solves (§6).
Sensitivity / false-positive rate \(\Pr(+\mid S)\), the chance a test flags a true case / \(\Pr(+\mid\neg S)\), the chance it wrongly flags a healthy one (§5).
Sequential recommendation Predict the next item from a user’s ordered history.
Serendipity Relevant and surprising: hits a popularity baseline would not have shown, divided by \(K\).
Serving path / serving Serving is answering a live request; the serving path is everything that runs between the request and the list shown (§1).
Session The ordered items one person goes through in one sitting, a visit or an evening; short, and sometimes anonymous.
Session-based recommendation Same, but from a short, often anonymous current session (no user id).
SGD Stochastic Gradient Descent — gradient steps on random mini-batches.
SGL / SimGCL / XSimGCL / LightGCL Self-supervised Graph Learning / Simple Graph Contrastive Learning / eXtremely Simple GCL / Light Graph Contrastive Learning — GCL methods differing in how the two views are built (edge-drop / embedding noise / cross-layer noise / SVD). Note the final letter: LightGCL is a training method, LightGCN the backbone.
Shape \(m\times n\) \(m\) rows by \(n\) columns.
Shrink factor \(1-2\eta\lambda\), what one L2 step multiplies a weight by (§5.1).
Shrinkage Multiplying a similarity by \(n/(n+\kappa)\), so one backed by few co-ratings \(n\) is pulled toward \(0\) (§4).
Side features Information about a user or film beyond clicks, such as genre or text (§4 box).
\(\sigma\) (nonlinearity) An activation function: the rectified linear unit (ReLU), \(\mathrm{ReLU}(z)=\max(0,z)\), in GCN, and LeakyReLU (a ReLU that lets a small slope through for negative inputs; NGCF’s paper uses it) in NGCF; removed in LightGCN. In this chapter \(\sigma\) means the sigmoid only inside the BPR loss of §15: \(\sigma(z)=1/(1+e^{-z})\), the S-shaped function that squeezes any number into \(0\) to \(1\).
Sigmoid / logit \(\sigma(z)=1/(1+e^{-z})\) squashes a raw score \(z\) (the logit) into \((0,1)\) (§2.2).
Sigmoid \(\sigma(z)\) \(\frac{1}{1+e^{-z}}\): an S-shaped curve squashing any \(z\) into the range between \(0\) and \(1\); \(\sigma'=\sigma(1-\sigma)\le0.25\) (§3).
Significance (paired \(t\)-test) Is a gain bigger than run-to-run seed noise? Report mean \(\pm\) standard deviation over seeds and a \(p\)-value.
Significance level \(\alpha\) The pre-set bar (usually \(0.05\)); reject \(H_0\) if \(p<\alpha\).
SimCLR A simple framework for contrastive learning of visual representations (Chen et al., 2020b, ICML); the source of the two-augmented-views recipe (§3.1).
Singular value \(\sigma\) The strength of an SVD pattern, \(A\mathbf{v}_i=\sigma_i\mathbf{u}_i\); \(\sigma_i=\sqrt{\lambda_i(A^{\top}A)}\ge0\), biggest first.
Singular value decomposition (SVD) A standard way to split a table of numbers into its main patterns (§13).
Singular value decomposition (SVD) \(A=U\Sigma V^{\top}\) Factor any matrix into orthonormal patterns (\(U,V\)) scaled by singular values (\(\Sigma\)).
Singular value decomposition, SVD (\(M=U\Sigma V^\top\)) Factorizes a (rectangular) matrix into patterns \(U,V\) and strengths \(\Sigma\); keeping the top-\(q\) is an ideal low-pass (LightGCL).
Singular vectors The columns of \(U\) (left, \(\mathbf{u}_i\): output directions) and of \(V\) (right, \(\mathbf{v}_i\): input directions).
Slate A whole page/list of recommended items — the (combinatorial) action in slate RL.
SlateQ Decomposes a slate’s value into per-item \(Q\)-values, making value-based slate RL tractable.
SLM Small language model (\(\approx 0.5\)–9B) — cheap, high-throughput; the recsys feature-generation workhorse.
Smooth / differentiable Has a derivative everywhere — no kinks or jumps; looks straight up close.
Soft-thresholding Move a weight a fixed amount toward zero and stop at \(0\) if it would cross: \(\lambda/2\) in §5.1’s one-weight solution.
Softmax Multi-class sigmoid; scores → a probability distribution.
Softmax output Multi-class output head: \(K\) scores → a probability distribution, paired with cross-entropy.
Sparse / one-hot feature A category encoded as all-zeros with a single \(1\); CTR rows stack millions of these.
Sparse matrix A table that is almost all zeros, stored as a list of its non-zero entries: \(10\) of the toy’s \(36\) (§15).
Sparse matrix-vector product Multiplying a sparse matrix by a vector (or by each column of a matrix) while adding up only its stored non-zero entries (§15).
Sparsity Most of \(R\) is unknown (MovieLens-20M: \({\sim}99.5\%\) empty); the core difficulty.
Spectrum The list of a matrix’s singular values, biggest first (§6); a quickly falling spectrum means a few pieces capture most of the matrix.
SSL (self-supervised learning) Training on an auxiliary task that needs no labels; supervision is manufactured from the data’s own structure.
Standard deviation \(\sigma\) \(\sqrt{\operatorname{Var}[X]}\); the spread in the same units as \(X\) (§1).
Standard error (SE) \(s_d/\sqrt n\) — how much an estimate wobbles across repeats; shrinks with more data.
State \(s\) A summary of the current situation; what the agent conditions on.
Static vs contextual word2vec gives one fixed vector per word; a Transformer gives a different vector per occurrence (context-dependent; §4.2).
Stochastic gradient descent (SGD) Gradient descent on a noisy gradient estimated from a random minibatch, not the full dataset.
Structured output Forcing an LLM to emit schema-valid JSON via constrained decoding — valid shape, not guaranteed-correct values.
Structured output / JSON mode Forcing the LLM to emit schema-valid JSON, so the result is very likely parseable (§5 still validates).
STT / ASR / TTS / WER Speech-to-text (= automatic speech recognition) / text-to-speech / word error rate — (substituted + deleted + inserted words) / words in the correct transcript. §7.
Student-\(t\) distribution The spread of \(t\)-values pure luck produces — a bell with fatter tails than the Gaussian when there are few pairs, shaped by the df (§8.3).
Subgradient A stand-in slope at a kink where the true derivative is undefined (e.g. any value in \([0,1]\) for ReLU at \(0\)).
Subword tokenization (BPE) Split text into reusable sub-word pieces by greedily merging the most frequent adjacent pair; fixed vocabulary, and no <UNK> when the base vocabulary is all 256 bytes (byte-level BPE); WordPiece and Unigram are relatives; SentencePiece is a library that runs BPE or Unigram (§5.3).
Supervised / self-supervised learning (SSL) Learning from examples that come with their correct answers / from a task the data sets for itself, with no human labels (§1, §11).
Surprise \(-\log p\) of what happened (§2.3).
Surprise / self-information \(-\log p(x)\); how surprising an outcome is (\(0\) if certain, \(\to\infty\) if rare).
SVD / singular value Singular value decomposition: a table of numbers written as a sum of simple patterns, each with a strength, its singular value (Linear Algebra for Machine Learning §6; used in §5).
Symmetric \(A=A^{\top}\); for a real symmetric matrix, the eigenvectors can be chosen mutually orthogonal (§5).
Symmetrically normalized adjacency \(\tilde{A}\) \(\tilde A = D^{-1/2}AD^{-1/2}\): entry \((u,v)\) is \(A_{uv}/(\sqrt{\deg u}\sqrt{\deg v})\). One multiplication by it is one propagation layer (§7).

T

Term Meaning
t-SNE / variational inference Drawing high-dimensional data as a 2-D map by making a KL divergence small / replacing a hard-to-compute posterior (§5) by the closest member of a simpler family, closest measured by KL (§7).
TALLRec An LLM fine-tuned on recommendation instructions: a Tuning framework to Align LLMs with Recommendation (§2.1).
Tangent The line that just touches a curve at a point; its slope is the derivative there (§1).
Tanh Hyperbolic tangent, \(\tanh(z)=\frac{e^{z}-e^{-z}}{e^{z}+e^{-z}}=2\sigma(2z)-1\) — a sigmoid stretched to \((-1,1)\).
Taylor / linear approximation \(f(x+\delta)\approx f(x)+f'(x)\delta\); a curve looks straight up close.
Temperature \(\tau\) Divides the scores before a softmax: a small \(\tau\) gives a nearly one-hot output, a large \(\tau\) a nearly uniform one (§3).
Test set / fold Data held back to measure a trained model / one of the \(k\) slices of cross-validation, each taking a turn as the test set (§8).
TF-IDF A way to turn text into a feature vector (term frequency × inverse document frequency).
The rated-set leak With explicit ratings, sending an update for item \(i\) reveals (to a server that knows whose it is) that the user rated \(i\), and the gradient is a scaled copy of the user’s vector; FedRec masks the rated set with decoy items (see §3).
Thompson sampling (Thompson, 1933) Keep a posterior per arm; sample one value from each and pull the largest sample.
TIGER The system that introduced Semantic-ID generative recommendation: Transformer Index for Generative Recommenders (§2.2).
Token One element of an input sequence — a word, a sub-word piece (§5.3) or, in a recommender, one item of a history; the unit attention works on (§4.1).
Top-\(K\) The \(K\) highest-scoring unseen items returned to the user.
TPR / FPR True- / false-positive rate: the share of the relevant / irrelevant items scoring at or above a threshold (a cut-off score); lowering the threshold step by step traces the ROC curve.
Trace Sum of a square matrix’s diagonal entries; equals the sum of its eigenvalues (shown here for \(2\times2\)).
Train/test split How held-out test data is chosen: a random split, leave-one-out (LOO: each user’s chronologically last interaction), or a global temporal split (one cut-off date for everyone).
Train–serve skew One case of the wider train/serve difference: the mismatch between the logged, sampled data a model is trained on and the whole live catalog it is served over (§8).
Transductive A model that keeps one stored vector per node seen in training and cannot embed a node it never saw; a brand-new user or film has no row in \(E^{(0)}\) (§14). The GCN paper uses the word in a different sense: test nodes are visible during training.
Transductive / inductive A model that can represent only the ids seen in training / one that can give a new id a vector from its content (§3).
Transformer A stack of (self-attention + add&norm + feed-forward + add&norm) blocks; no recurrence, so training processes all positions in parallel (Vaswani 2017; §4.3).
Transition probability \(P(\text{next}=i\mid\text{last}=l)\) — count of \(l\!\to\!i\) over count of \(l\)-as-from.
Transpose \(A^{\top}\) The matrix mirrored across its diagonal (rows ↔︎ columns).
Triple A training example \((u,i,j)\): a user, a film she liked, and a film she has no edge to (§13, §15).
Triple \((u,i^+,i^-)\) A training example for pairwise ranking: user \(u\) prefers positive \(i^+\) over sampled negative \(i^-\).
Truncated SVD Keep the top-\(q\) singular components = best low-rank approximation (least-squares / Frobenius sense — the Eckart–Young theorem).
Two-stage funnel Retrieval → ranking: fast-and-forgiving then slow-and-sharp, so a rich model can run on only a few hundred candidates; the final cut applies the already-seen filter and any business rules, then shows the top \(K\).
Two-tower LLM-embedding retrieval Embed users and items with an LLM-grade encoder offline, then retrieve by ANN over those vectors at serve time: enhancer-class cost, LLM semantics on the retrieval path (§4).
Two-tower model Embeds user and item with two separate networks and scores by dot product; trained with sampled softmax (§10).
Type I / II error False positive (reject true \(H_0\)) / false negative (miss a real effect).

U

Term Meaning
UCB Pull \(\arg\max_i\,[\hat\mu_i + \sqrt{2\ln t / n_i}\,]\), with \(t\) the pulls so far and \(n_i\) the pulls of arm \(i\): highest upper bound, optimism under uncertainty.
Uniform / popularity-weighted / in-batch / hard negatives Four sampling distributions for \(i^-\): equal-probability; \(\propto\text{pop}^{0.75}\); reuse the batch’s other positives; pick high-scoring (confusing) items.
Uniformity Embeddings spread evenly over the sphere. It is the term that scores collapse as worst (§3.3); that it also helps the long tail is the papers’ claim, not tested here.
Unit circle / semi-axes The unit circle is all vectors of length \(1\); a matrix sends it to an ellipse, whose longest and shortest radii (the semi-axes) have lengths \(\sigma_1,\sigma_2\) (§6).
Unit vector A vector of length \(1\); “normalizing” = dividing by your own length.
Unit vector / unit hypersphere A vector of length 1; the set of all such vectors, a circle in 2-D (§3.3).
Universal approximation A wide enough net can approximate any continuous function on a bounded region.
User profile The average of the feature vectors of the items a user liked; content-based filtering scores items against it (§2).
User simulator A model of user behavior used to train RL without experimenting on real users.
User–item matrix \(R\) Rows = users, cols = items, entries = ratings/clicks (mostly unknown).

V

Term Meaning
Validation loss The loss on held-out examples the network never trains on — a stand-in for new data (§6).
Validation set A slice of the data held out from training and used only to measure progress (§5.2).
Value / \(Q\)-value Expected return from a state (\(V\)) or a state–action pair (\(Q\)).
Vanishing gradient A chain-rule product of many small factors shrinks toward zero, so early layers stop learning (§3, §8; see also the §5 box on gradient pathologies).
Variance \(\sigma^2\) Expected squared distance from the mean; spread.
Variational autoencoder (VAE) / ELBO A network that learns to generate new data / its training objective, the evidence lower bound, which can never exceed the log of the evidence (§5); it contains a KL term that keeps each example’s code near a prior (§7).
Vector An ordered list of numbers; equivalently, an arrow from the origin to a point.
Vector-wise vs bit-wise A cross with one weight per pair of whole field vectors (xDeepFM’s CIN) versus one weight per coordinate (DCN, an MLP).
View The embedding a node gets after an augmented input is encoded; contrastive learning needs two per node (§3.1).

W

Term Meaning
\(W\) (weight matrix) Learnable feature transform in GCN/NGCF; removed in LightGCN.
Walk A path of \(K\) steps along edges that may turn back (Ann, Titanic, Ann); layer \(K\) mixes the starts of nodes a \(K\)-step walk reaches (§5).
Weight One adjustable multiplier in a layer’s weighted sum; the main kind of parameter in a neural network (§3).
Weight / bias Learned multiplier per input / learned constant offset.
Weight decay The L2 penalty \(\lambda\lVert W\rVert^2\) on the weights; its gradient \(2\lambda W\) shrinks every weight a little at each step (§7).
Weighted / unweighted Whether edges carry a number (rating/count) or are just 0/1.
Weighted sum Scale several vectors by numbers and add the results, e.g. \(1\cdot[2,1]+2\cdot[0,3]=[2,7]\).
Weights A model’s learned parameters, collected in one list \(\theta\) (§6), the numbers a regularizer keeps small.
Wide & Deep Joint linear-with-hand-crosses over the raw features (memorize) \(+\) MLP-over-embeddings (generalize) model.
Wilcoxon signed-rank Non-parametric paired test (ranks, not values); use when differences aren’t normal and there are at least \(6\) pairs (below that it cannot reach \(p<0.05\); §8.6).
word2vec Predict-based word embeddings trained on word–context prediction: skip-gram predicts the context from a word, CBOW the word from its context (Mikolov 2013a, 2013b; §2.2).
WRMF / ALS Weighted Regularized MF / Alternating Least Squares (implicit-feedback, squared error).

Term Meaning
Xavier / Glorot init The same idea for symmetric activations (tanh, sigmoid): variance \(2/(\text{fan\_in}+\text{fan\_out})\), with fan_out = neurons in the layer (§6).
xDeepFM / AutoInt / DIN Vector-wise crosses (CIN) / attention-learned interactions / per-candidate behavior attention.

Zero-shot NER Extracting arbitrary entity types with no task-specific training (GLiNER, NuNER-Zero).
